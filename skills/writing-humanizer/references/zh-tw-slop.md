# 台灣正體中文 AI 詞彙與句式

這些詞在 AI 生成的中文裡出現頻率異常偏高。遇到就替換或刪除。

## 高頻詞替代表

| AI 高頻詞 | 替代 |
|---|---|
| 此外 | 也、另外、還有（或直接刪除） |
| 至關重要 | 重要、很重要（或具體說明為何重要） |
| 深入探討 | 討論、分析、看看 |
| 強調／突出／彰顯 | 提到、指出、說（或直接刪除） |
| 持久的／永恆的／持續的 | 一直、長期、到現在還 |
| 增強／提升 | 改善、變好、讓……更好 |
| 培養／促進／涵養 | 練、學、養成 |
| 獲得／贏得 | 拿到、得到 |
| 格局（抽象名詞） | 情況、狀況、現況 |
| 關鍵性的／樞紐性的 | 重要的（或具體說明） |
| 展示／展現 | 讓人看到、呈現 |
| 織錦／畫卷（比喻） | 刪除，改成具體描述 |
| 寶貴的 | 有用的、有價值的 |
| 充滿活力的 | 熱鬧的、活潑的（或具體描述） |
| 不可磨滅的 | 深遠的、很大的 |
| 相互作用／交織 | 互相影響、一起 |
| 複雜性／錯綜複雜 | 複雜、麻煩 |
| 無縫的／無縫銜接 | 順暢的、順利的 |
| 賦能／賦予力量 | 幫助、讓……能夠 |
| 奠定基礎 | 打底、開始 |

## 句式模板

| AI 句式 | 處理方式 |
|---|---|
| 在當今……的時代 | 刪除，直接進入主題 |
| 隨著……的快速發展 | 簡化或刪除 |
| 值得一提的是 | 直接說 |
| 不容忽視的是 | 直接說 |
| 眾所周知 | 刪除，直接陳述 |
| 總而言之／綜上所述 | 簡化或刪除 |
| ……的重要性不言而喻 | 具體說明為什麼重要 |
| 這不僅……更是…… | 違反鐵律。直接陳述。 |
| 從……到……，從……到…… | 舉一兩個具體例子 |
| 讓我們一起…… | 刪除，或直接說明行動 |
| 本文將探討／本節將分析 | 刪除導讀宣告，直接講內容 |
| 理解了……，我們就能明白 | 刪除，信任讀者自己連結 |
| 為……奠定了基礎／提供了重要框架 | 刪除意義蓋章，或寫具體後果 |
| 具有重要的戰略意義／發揮關鍵作用 | 刪除，或具體說明影響了什麼 |
| 願我們……／讓我們都能…… | 刪除升華呼告，收在事實 |
| 歷史將會記住…… | 刪除 |
| 這項神聖的……／不可磨滅的…… | 刪除神聖化修辭 |
| 為……世界和平作出更大貢獻 | 刪除空泛樂觀結尾 |
| 每一……都是……，每一……都是…… | 刪除排比金句 |
| 我們是選擇了 X 還是 Y | 刪除是非排比 |

## 填充短語

| 填充短語 | 替代 |
|---|---|
| 為了實現這一目標 | 為了 |
| 由於下雨的事實 | 因為下雨 |
| 在這個時間點 | 現在 |
| 在您需要幫助的情況下 | 如果你需要幫助 |
| 系統具有處理的能力 | 系統可以處理 |
| 值得注意的是資料顯示 | 資料顯示 |
| 在當今快速發展的時代 | 刪除，直接進入主題 |
| 隨著科技的不斷進步 | 刪除或簡化 |

## 必刪的開場白與贅詞

開場白：事情是這樣的／令人不安的真相是／事實證明／讓我直說吧／老實說／我們來談談／有趣的是／問題在於

強調贅詞：就是這樣。／讓這個沉澱一下。／這很重要，因為／毫無疑問／這就是為什麼它重要

二元對比：不是因為 X。而是因為 Y。／X 不是問題。Y 才是。／答案不是 X。而是 Y。

戲劇性分段：[名詞]。就這樣。就是這個[東西]。／X。還有 Y。還有 Z。
